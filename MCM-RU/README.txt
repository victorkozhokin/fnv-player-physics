Русский текст меню MCM -- необязательно
=======================================

Скопируйте файл из Translations\ поверх одноимённого файла в

    Data\MCM\Translations\

Заменяются только подписи и подсказки в меню. Настройки, их значения и
поведение мода не меняются, английский вариант можно вернуть в любой момент,
положив назад исходный файл из архива.
