; Tells the plugin when another mod is moving the player, so the movement
; solve stands down for exactly that and nothing else.
;
; Begin and End are counted, not flagged; every Begin needs its End, and the
; plugin releases anything still raised after 30 seconds.

PPScriptLayerReady

; B42 Interact. Its own loop counts the pull down at 62.5 units per second, so
; the end is known up front and no second event is needed. Arg 4 is the distance.

SetEventHandlerAlt "B42Rap" (begin Function {ref rObject, string_var sNode, float fDist, float fDuration}

	PPBeginInteraction

	CallAfter ((fDuration / 62.5) + 0.15) ({} => PPEndInteraction)

end)
